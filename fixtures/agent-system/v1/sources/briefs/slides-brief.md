# Brief: review deck for the PV-2201 assessment

**Deliverable:** one PowerPoint file (`.pptx`), four slides, for a 10-minute
Technical Services review.

## Slides

1. **Title** — vessel tag, inspection date, presenter line.
2. **Readings** — the four ultrasonic points as a table, the governing value
   identified.
3. **Assessment** — the applicable minimum, the revision it comes from, the
   wall loss, and the replacement date.
4. **Recommendation** — the action, its deadline, and who must approve it.

## Constraints

- Every slide carries a title. A slide with no heading cannot be reviewed.
- Slide 3 must name the SOP revision applied. If the carve-out in Revision D
  section 3.1 is engaged, slide 3 must say so.
- No slide may assert a remaining-life figure. The inspection report explicitly
  declines to make one, and a deck that invents it has invented it.
